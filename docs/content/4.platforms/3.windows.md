title: Windows
description: Credential Manager storage, its size limit, and case-insensitive names.
---

Entries go to the **Windows Credential Manager** as generic credentials
(`windows-native-keyring-store`). No setup is needed; there are no prompts.

## Size limit

Credential Manager allows at most **2560 bytes** per secret, and text is stored as UTF-16 (2 bytes per
character):

| What | Real limit |
|------|-----------|
| Password account secret | about **1280** UTF-16 characters |
| Store record or vault secret | about **960 bytes** of raw data (Base64 makes it 4/3 larger, then UTF-16 doubles it) |

Larger writes fail with a `keyring error: …`. Vault keys made by the procedures (65 bytes) fit easily.
Split large data or keep it in an encrypted file and store only its key here.

## Names ignore case

Credential names are case-insensitive: `App.Token` and `app.token` are the same entry. The plugin's
[`kp:` guard](/guides/passwords#reserved-accounts) ignores case for this reason.

## Where to see them

Control Panel → Credential Manager → Windows Credentials → Generic Credentials, or `cmdkey /list`.
